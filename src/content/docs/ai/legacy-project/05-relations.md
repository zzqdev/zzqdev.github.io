## CLAUDE.md：放什么、不放什么

| 放 | 不放 |
| --- | --- |
| 一句话定位 | 架构图文字重抄 |
| 架构一段话 + 链到 svg | 完整 api-list |
| 模块小表 | 完整字段表 |
| 硬规则约定 | 通用开发手册 |
| 怎么跑 + 链接 | 诞生史散文 |
| 禁区 / 历史包袱（人手） | AI 猜的雷 |

用手册生成初稿；太长就「压成一句话+链接」；禁区两节**留白给人写**。

**人手必补骨架：**

```markdown
## 禁区
- （字段/路径/配置：谁依赖、为什么不能动）

## 历史包袱
- （看起来怪、其实有原因：勿顺手重构）
```

**验收：** ≤ ~300 行；详版靠链接；禁区/包袱是真内容或诚实「待补充」。

## Skill：三特征再写

**可复制 · 可参数化 · 可自动化**——缺一不写。  
仓库先养 3 个高频，总量常 ≤ 5。

常见富矿：文档自动更新、改造前体检、PR 前检查、加接口前对齐。

流程：手册「挖候选」→「Top 3」→「生成 docs-auto-sync」→ 重启 → 正/反例验证。

| 类型 | 期望 |
| --- | --- |
| 「刚改完 Controller，文档还对得上吗」 | 触发校对 |
| 「帮我检查一下这段代码」 | 不误触发 |
