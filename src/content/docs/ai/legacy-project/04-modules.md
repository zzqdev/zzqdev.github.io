## REST 清单：坑与验收

| 坑 | 你怎么拦 |
| --- | --- |
| 只扫一个子模块 | 手册「防漏扫」两句 |
| 数量异常偏少 | 追问扫了几个模块 |
| 只有路径没有意图 | 强制一句话说明 |
| 字段展开成百科 | 主要结构即可，细节进模型文档 |

**验收：** 按模块可读；方法/路径/说明/主要 IO 齐全；多模块无漏扫。

---

## 数据模型 + ER：坑与验收

| 坑 | 你怎么拦 |
| --- | --- |
| 只信表名猜字段 | 强制读 DDL / migration |
| entity=DTO=表 | 三层分开写清映射 |
| 漏隐式关联 | 用 `findBy` / 手工 join 反查 |

**验收：** DB 骨架清晰；主外键/枚举标出；ER 与 md 一致。

---

## 互校（必做）

跑手册「互校」提示词后，用口诀收尾：

- 接口 → 能指到 Controller 与返回类型  
- 字段 → 模型文档里有解释  
- 模型 → 知道被哪些接口用  
- 矛盾 → **回代码证据**，不靠「说得通」
