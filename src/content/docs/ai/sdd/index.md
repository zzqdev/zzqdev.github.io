SDD（Spec-Driven Development）把「先想清楚再写代码」落到可执行工件上：规格是合同，实现与测试都对着合同走。

适合用 AI 协作写功能时：人负责定边界与验收，Agent 负责按规格落地；改需求先改规格，再改代码。

## 最短路径（草稿）

1. 用一两句话写清目标与非目标  
2. 列出接口 / 行为 / 边界条件（可测）  
3. 再让 Agent 按规格实现，用同一份规格做 review
