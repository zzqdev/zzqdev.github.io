Vben 中采用了 monorepo 的组织形式
### monorepo 是什么
是一个工程化的项目代码组织规范， 一个仓库中管理多个应用，易于代码复用

规范经历了多个阶段
1. 单仓库
2. 多仓库多模块
3. 单仓库多模块（monorepo）

单仓库 - 多仓库多模块 - 单仓库多模块（monorepo）

必用pnpm： 解决幽灵依赖

[turborepo](https://turborepo.dev/)

[更详细的介绍](https://juejin.cn/post/7215886869199896637?searchId=20260417155012D458B9D842EFDF6FC9AF)

#### 根目录
- **apps**: 存放应用
- **packages**: 共享包
- **internal**: 内部用的工具与配置（例如与构建、工具链相关的封装）

##### apps下应用的 src
## `src` 下常见文件/目录与作用

| 文件 / 目录 | 作用 |
|------------|------|
| `main.ts` | 入口：创建应用、挂载根组件 |
| `app.vue` | 根组件 |
| `bootstrap.ts` | 启动流程（常配合异步初始化） |
| `preferences.ts` | 本应用偏好/主题等配置入口 |
| `router/` | 路由定义、`guard.ts`、权限 `access.ts`、按模块拆分的 `routes/`（如 `routes/modules/*.ts`） |
| `views/` | 页面组件；`views/_core/` 里是登录、个人中心、异常页、关于等基础页面（见该目录 `README.md`） |
| `layouts/` | 布局壳，如 `basic.vue`、`auth.vue` |
| `api/` | 对接后端的请求封装、各业务 API（如 `api/request.ts`、`api/core/*.ts`） |
| `store/` | Pinia 等本应用状态（如 `auth.ts`、`index.ts`） |
| `locales/` | 本应用 i18n 与对 dayjs、Ant Design 等的多语言扩展（见 `locales/README.md`） |
| `adapter/` | 把通用能力接到具体 UI 库（表单、表格等）的适配层（如 `adapter/form.ts`、`adapter/component/`） |
